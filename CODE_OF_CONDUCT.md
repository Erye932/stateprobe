# Code of Conduct

StateProbe is intended to be a useful, evidence-conscious open-source project for developers and AI researchers.

## Expected behavior

- Be respectful and constructive.
- Critique ideas, rules, prompts, and evidence; do not attack people.
- Keep claims precise and grounded in the evidence model.
- Help make issues and pull requests actionable.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Sharing private prompts, secrets, API keys, or customer data.
- Repeatedly overstating what StateProbe can prove after maintainers clarify the evidence boundary.
- Spamming issues or pull requests with low-effort promotion.

## Evidence culture

This project welcomes disagreement when it improves accuracy. If you think a rule is wrong, open an issue with:

- The prompt pattern
- The expected axis behavior
- Why the current reading is wrong
- A better rule, example, or citation if available

## Enforcement

Maintainers may edit, close, or remove contributions that violate this code of conduct or create security risk.
