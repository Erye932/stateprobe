# 你每天写的 Prompt，正在悄悄激活 AI 的「迎合模式」

你有没有这种经历——

问 AI 一个问题，它洋洋洒洒写了两千字，看着很专业，但仔细一读：**全是正确的废话。**

不是 AI 笨。是你的 Prompt 把它推进了错误的行为状态。

---

举个例子。你写：

> 你是资深专家，请全面分析这个项目，多讲讲优点和潜力。

这句话干了三件事：

1. 「资深专家」→ 激活装腔模式，它开始端着说话
2. 「全面分析」→ 激活发散模式，什么都说一点，什么都不说透
3. 「多讲优点」→ 激活迎合模式，不敢说不行

**你以为你在提需求，其实你在给 AI 下毒。**

这不是玄学。Anthropic 2025 年的论文已经证明：迎合、幻觉、装专家这些行为，在大模型内部对应着可测量的向量方向。你的措辞会按强度激活它们。

问题是——你看不见。

---

所以我做了 **StateProbe**，一个开源的 Prompt 调试器。

输入你的 Prompt，它告诉你：

- 你在 8 个行为轴上激活了什么（迎合度、任务宽度、身份感、推理预算…）
- 哪些词是「污染源」
- 怎么改

拿刚才那个坏 Prompt 跑一下：

```
身份强度  ████████░░  75%  ← 「资深专家」
任务宽度  ████████░░  77%  ← 「全面」
迎合度    ██████░░░░  65%  ← 「多讲优点」
对齐度: 31%  ⚠️ 严重偏离
```

*▲ StateProbe 生成的可视化报告：蓝色实线是当前 Prompt 的行为读数，橙色虚线是目标状态。偏差越大，问题越严重。*

（图片：docs/images/demo_report.png）

改写建议：删掉身份赋予，删掉发散词，加一句「不值得就直说」，加失败标准。

改完：

> 判断这个项目是否值得继续投入。不要鼓励，不值得直接说。结论必须能指导今天取舍。

你一眼就知道哪个 Prompt 更能让 AI 干活。StateProbe 把这种「直觉」变成了可量化的诊断。

---

**说实话的部分：**

正则规则有覆盖盲区。比如下面这条**温和措辞的迎合陷阱**：

> 我希望你能完全客观地评估，**不过也希望你多看到积极的一面**，毕竟我也投入了不少时间。

正则在这条上抓到 **0 条污染源**——它读不懂这种语义压力。

这是 v0.2 加 LLM 层的原因。开 `--llm-augment`，LLM 层会精准抓到 「多看到积极的一面」，给出 90% 置信度的迎合证据。两层证据合并到同一个池子里聚合——不是二选一，是叠加。

我之前真的犯过一个错：v0.2 dev 版本做成了 `--engine static|llm` 二选一架构。让用户选盲区，等于把工具的失败转嫁给用户。压力测试发现后我重做了，写在 ADR_009 里公开复盘。

它不是 AI 读心术——是体检工具，不是 CT 扫描。真正的"读模型内心"在 v0.4：拿开源 DeepSeek MoE 直接看专家路由。

---

**30 秒上手：**

```bash
git clone ssh://git@ssh.github.com:443/Erye932/stateprobe.git
cd stateprobe && pip install -e .

stateprobe demo                          # 看完整诊断
stateprobe check "你的prompt"             # 默认零成本静态层
stateprobe check --llm-augment "..."     # 加 LLM 语义层
```

默认模式零 API 调用，零成本，毫秒响应，可离线。
